NookureStaff provides a dedicated event bus managed by `EventManager` (`com.nookure.staff.api.event`), allowing developers to listen and respond to staff workflows, sanctions, and network packets.

---

## Staff & Moderation Events

| Event Class | Package | Description |
|---|---|---|
| `StaffModeUpdatedEvent` | `com.nookure.staff.api.event.staff` | Fired when a staff member enables or disables Staff Mode. |
| `StaffVanishUpdatedEvent` | `com.nookure.staff.api.event.staff` | Fired when a staff member toggles vanish on or off. |
| `StaffDisconnectEvent` | `com.nookure.staff.api.event.staff` | Fired when a staff member disconnects from the server. |
| `PunishmentCreatedEvent` | `com.nookure.staff.api.event.punishment` | Fired when any sanction (Ban, Mute, Warn, Kick) is created. |
| `PunishmentEvidenceAddedEvent` | `com.nookure.staff.api.event.punishment` | Fired when evidence URL/link is attached to an existing sanction. |
| `PunishmentPardonedEvent` | `com.nookure.staff.api.event.punishment` | Fired when a sanction is unbanned, unmuted, or pardoned. |

---

## Action & Player Events

| Event Class | Package | Description |
|---|---|---|
| `ActionRecordedEvent` | `com.nookure.staff.api.event.action` | Fired whenever an action log entry is saved into the database. |
| `PlayerJoinEvent` | `com.nookure.staff.api.event.player` | Fired when a player wrapper is initialized upon connection. |
| `PlayerLeaveEvent` | `com.nookure.staff.api.event.player` | Fired when a player wrapper is destroyed on disconnection. |
| `PlayerModelLoadedEvent` | `com.nookure.staff.api.event.player` | Fired once the player's persistent database model finishes loading. |

---

## Cross-Server Messenger Events

When using Redis or Velocity Plugin Messaging, these network packet events are dispatched across all instances:

- `MStaffModeEnabledEvent` & `MStaffModeDisabledEvent`: Broadcasts staff mode transitions across servers.
- `MPunishmentCreatedEvent`: Informs all network instances to drop or update local caches upon new bans/mutes.
- `MPunishmentPardonedEvent`: Informs all network instances of a pardon.

## Registering an Event Listener

Annotate listener methods with `@NookSubscribe` (from `com.nookure.staff.api.event.NookSubscribe`) and register the listener instance with `EventManager`:

```java
import com.nookure.staff.api.NookureStaff;
import com.nookure.staff.api.event.EventManager;
import com.nookure.staff.api.event.EventPriority;
import com.nookure.staff.api.event.NookSubscribe;
import com.nookure.staff.api.event.staff.StaffModeUpdatedEvent;
import org.bukkit.Bukkit;

public class MyStaffListener {

    @NookSubscribe(priority = EventPriority.NORMAL)
    public void onStaffModeToggle(StaffModeUpdatedEvent event) {
        boolean isNowInStaffMode = event.staffMode();
        var staffPlayer = event.player();

        System.out.println(staffPlayer.getName() + " staff mode is now: " + isNowInStaffMode);
    }
}
```

Register your listener in your plugin's `onEnable()`:

```java
NookureStaff staffApi = Bukkit.getServicesManager().load(NookureStaff.class);
if (staffApi != null) {
    EventManager eventManager = staffApi.getInjector().getInstance(EventManager.class);
    eventManager.registerListener(new MyStaffListener());
}
```
