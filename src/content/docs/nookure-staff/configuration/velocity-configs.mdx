When running a Bungee-alternative network using **Velocity 3.4+**, `NookureStaff-Velocity` acts as the security boundary.

---

## `velocity.yml`

Located at `plugins/nookurestaff/velocity.yml`:

```yaml title="plugins/nookurestaff/velocity.yml"
# Enable debug messages in the Velocity proxy console
debug: false

# Prefix for proxy-level staff broadcasts
prefix: "<gradient:#ff5e62:#ff9966><b>[Network Staff]</b></gradient> "

# Database configuration (must point to the same MySQL database as backend Paper servers)
database:
  type: MYSQL
  host: localhost
  port: 3306
  username: nookure
  password: yourSecurePassword
  database: database

modules:
  # Enables proxy-side punishment rejection on pre-login
  punishment-module: true

# Enable or disable automatic error reporting to GlitchTip
error-reporting: true
```

---

## Velocity Punishment & Pre-Login Gate

Because Velocity sits between players and backend Paper servers:
1. `PunishmentLoginListener` intercepts `PreLoginEvent` on Velocity.
2. If the connecting UUID or IP is flagged with an active Ban or IP-Ban, the connection is aborted immediately.
3. The player receives the kick message defined in `plugins/nookurestaff/punishment/messages.yml` without taxing backend server resources.
