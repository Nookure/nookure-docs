When a staff member enters Staff Mode, their inventory is replaced with a customized hotbar defined in `plugins/NookureStaff/items.yml`. NookureStaff ships with 7 pre-configured moderation tools and an engine for creating custom command items.

---

## Default Built-in Items

| Slot | Item Type | Material | Default Name | Permission Node | Functionality |
|---|---|---|---|---|---|
| **0** | `RANDOM_PLAYER_TELEPORT` | `ENDER_PEARL` | `<green>Random Teleport</green>` | `nookurestaff.item.randomteleport` | Teleports staff to a random online player. |
| **1** | `FREEZE` | `BLAZE_ROD` | `<aqua>Freeze Player</aqua>` | `nookurestaff.item.freeze` | Right-clicking a player freezes or unfreezes them. |
| **3** | `ENDER_CHEST` | `ENDER_CHEST` | `<purple>Ender Chest</purple>` | `nookurestaff.item.enderchest` | Opens target player's live ender chest. |
| **4** | `VANISH` | `ENDER_EYE` | `<gray>Vanish Toggle</gray>` | `nookurestaff.item.vanish` | Toggles vanish mode on right-click. |
| **5** | `INVSEE` | `CHEST` | `<gold>Inspect Inventory</gold>` | `nookurestaff.item.invsee` | Opens target player's live survival inventory. |
| **7** | `NIGHT_VISION` | `POTION` | `<blue>Night Vision</blue>` | `nookurestaff.item.nightvision` | Toggles infinite night vision effect. |
| **8** | `THRU` | `COMPASS` | `<red>Thru Compass</red>` | `nookurestaff.item.thru` | Teleports through the targeted solid wall or barrier. |

## Custom Items Engine

You can add an unlimited number of custom items to `items.yml` to trigger commands on right-click.

### Execution Types

When defining a custom item, set `type` to one of the following:

- **`COMMAND_AS_PLAYER`**: Runs the command as the player who clicked the item.
- **`COMMAND_AS_CONSOLE`**: Runs the command as the console.
- **`COMMAND_TARGET_AS_PLAYER`**: Runs the command as the staff member with `{target}` replaced by the player that was clicked.
- **`COMMAND_TARGET_AS_CONSOLE`**: Runs the command as the console with `{target}` replaced by the player that was clicked.

### Example Custom Item Configuration

```yaml title="plugins/NookureStaff/items.yml"
custom-items:
  custom_item:
    # The type of the custom item:
    # COMMAND_AS_PLAYER, COMMAND_AS_CONSOLE, COMMAND_TARGET_AS_PLAYER, COMMAND_TARGET_AS_CONSOLE
    type: COMMAND_TARGET_AS_PLAYER

    # The command to execute when the item is clicked.
    # You can use {player} for the staff member and {target} for the clicked player.
    command: msg {target} Hello, world!

    # Whether the item is enabled or not.
    # If the item is disabled, it won't be shown to anyone.
    enabled: false

    # The permission required to use the item.
    # If the player doesn't have the permission, the item won't be shown.
    permission: nookurestaff.item.custom

    # The name of the item (supports MiniMessage, hex <#hexcode>, gradients, and &/§).
    name: <blue>Custom Item

    # The Bukkit Material of the item.
    material: DIAMOND

    # The hotbar slot of the item (0 to 8, from left to right).
    slot: 2

    # The lore of the item (supports MiniMessage, hex <#hexcode>, gradients, and &/§).
    lore:
      - <gray>Click to send hello world to the player that you are looking at
```
